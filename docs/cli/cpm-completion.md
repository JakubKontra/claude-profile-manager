# cpm completion

Generate the autocompletion script for cpm for the specified shell.
See each sub-command's help for details on how to use the generated script.

## Usage

```
cpm completion [flags]
```

## Global flags

- `--config string`: path to config file (default ~/.claude-profiles/config.toml)

## Commands

- [cpm completion bash](cpm-completion-bash.md): Generate the autocompletion script for bash
- [cpm completion fish](cpm-completion-fish.md): Generate the autocompletion script for fish
- [cpm completion powershell](cpm-completion-powershell.md): Generate the autocompletion script for powershell
- [cpm completion zsh](cpm-completion-zsh.md): Generate the autocompletion script for zsh

See also [cpm](cpm.md).
